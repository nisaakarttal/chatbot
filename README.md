# AI Chatbot Project

Yapay zeka destekli bu chatbot projesi, kullanıcılarla doğal dil üzerinden etkileşim kurabilen modern bir web tabanlı sohbet sistemidir. Proje, kullanıcı dostu bir arayüz ile güçlü backend altyapısını birleştirerek hızlı ve akıllı cevaplar üretmeyi amaçlar.

---

## Proje Özeti

Bu proje kapsamında:

* Kullanıcı mesajlarını işleyen bir chatbot sistemi geliştirildi.
* OpenAI entegrasyonu ile yapay zeka destekli yanıt mekanizması oluşturuldu.
* JSON ve TXT veri yapıları kullanılarak test süreçleri gerçekleştirildi.
* FastAPI tabanlı backend mimarisi kuruldu.
* Modern ve sade bir frontend arayüzü tasarlandı.

## Kurulum

### Depoyu Klonlayın

```bash
git clone <repo-link>
cd chatbot
```

### Gerekli Paketleri Kurun

```bash
pip install -r requirements.txt
```

### Uygulamayı Başlatın

```bash
uvicorn main:app --reload
```
